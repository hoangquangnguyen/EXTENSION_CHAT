- (event) user selected Coaching path
- (question) how to handle MV3 Service Worker lifetime vs persistent WebSocket connection to localhost?
- (decision) use Offscreen Document to host the persistent WebSocket connection to localhost to bypass MV3 service worker lifetime limits
- (question) how should the configurable CSS selectors (FR-10) be managed and updated?
- (decision) load CSS selectors from default selectors.json into chrome.storage.local, exposing a settings panel in the UI to allow dynamic updates without reloading code
- (question) how to handle comment scraping when localhost connection is disconnected (discard vs buffer vs pause DOM observer)?
- (decision) buffer captured comments in a memory queue (max 100) during localhost disconnection, flushing them immediately upon reconnection
- (question) should the WebSocket message payload use a flat structure or a typed envelope to support future events like likes or gifts?
- (decision) use a flat JSON payload structure for WebSocket messages as specified in the PRD, containing platform, nickname, username, message, profilePic, and timestamp directly
- (question) how to handle chat container DOM changes/reloads to prevent observer disconnection?
- (decision) implement an auto-reattach loop in the Content Script that checks every 2 seconds if the chat container is still attached and active, re-binding the MutationObserver dynamically if the container is replaced or reloaded
- (question) where should the last 20 comments preview history be stored (in-memory Popup vs persistent-in-session background Script)?
- (decision) store the last 20 comments preview queue only in the Popup UI's active memory; the list resets when the Popup is closed and reopened
